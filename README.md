# Supply Chain Delivery Performance Analysis

This project analyzes 5,000 simulated delivery orders to identify the main drivers of late deliveries, higher delivery costs, and inconsistent carrier performance.

## Business problem

A logistics company needs to understand why some deliveries arrive late, which carriers underperform, and where operational improvements can improve on-time delivery.

## Tools used

- Python
- pandas
- Matplotlib
- SQL
- Excel-style KPI reporting

## Dataset

The project uses a synthetic dataset of 5,000 delivery orders with:

- Order ID
- Order date
- Delivery date
- Carrier
- Region
- Rural or urban delivery flag
- Planned delivery days
- Actual delivery days
- Delivery cost
- Delivery status

The dataset is generated by `data/generate_data.py`, so the project is fully reproducible.

## Analysis approach

1. Generate and inspect the delivery dataset.
2. Clean dates, calculate delivery duration, and classify orders as on-time or late.
3. Calculate overall on-time delivery rate, average delivery time, and average delivery cost.
4. Compare carrier performance, regional performance, and rural versus urban delivery performance.
5. Analyze monthly delivery trends and identify peak-season delays.
6. Create visualizations and recommend operational actions.

## Key findings

- One carrier achieved only 64% on-time delivery, compared with 82% for the best-performing carrier.
- Rural deliveries had a 61% on-time rate, lower than urban deliveries.
- November and December delivery performance dropped to 63-68%, compared with 76% overall.
- Carrier volume rebalancing, rural delivery buffers, and peak-season capacity planning can improve delivery reliability.

## How to run

```bash
pip install -r requirements.txt
python data/generate_data.py
python analysis/delivery_analysis.py
```

The analysis script creates charts in the `output/` folder.

## Files

- `data/generate_data.py`: creates the synthetic delivery dataset
- `analysis/delivery_analysis.py`: performs the analysis and creates charts
- `sql/delivery_queries.sql`: SQL queries for delivery KPIs and carrier analysis
- `requirements.txt`: Python dependencies
